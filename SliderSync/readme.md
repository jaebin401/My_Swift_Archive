# SliderSync

## 작성일자
2026.05.27

## 학습 목표
- 애플워치와 아이폰의 실시간 연동을 위해 WatchConnectivity 프레임워크 사용방법을 숙지한다.

## 학습 맥락
- C3의 CoreMotion 및 애플워치 활용 어플 제작에 워치와 아이폰의 실시간 데이터 연동이 필요하여 관련 내용 학습
- 위 필요에 필요한 프레임워크가 WatchConnectivity. 그 사용방법을 위해 관련 인스턴스와 사용방법 숙지
- 실습 시나리오: 아이폰의 슬라이더로 실수값(0~1)을 조절하면, 그 값이 애플워치 화면에 실시간으로 표시되는 단방향 스트리밍 앱
